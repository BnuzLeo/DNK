# 弹道系统 (Projectile System)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 碰撞检测*
*Depended on by: 射击系统, 打击反馈*

---

## 1. Overview

弹道系统负责管理游戏中所有子弹（弹道）的生命周期：生成、飞行、碰撞、销毁。它是弹幕密度的技术基础 — 100+ 子弹同时在屏幕上飞舞，需要高效的对象池管理来保证 Web 端 60fps。

---

## 2. Player Fantasy

玩家感受到的：子弹像雨一样倾泻，屏幕被弹幕填满，但不卡顿。每一发子弹都有清晰的视觉存在感（发光轨迹），命中时有即时反馈。

支柱 1（弹幕爽感）要求：子弹密度是核心卖点。支柱 2（即时反馈）要求：子弹命中瞬间有视觉确认。支柱 4（像素酷炫）要求：子弹是最亮的光源。

---

## 3. Detailed Rules

### 3.1 子弹类型

| 类型 | 来源 | 碰撞层 | 默认速度 | 默认伤害 |
|------|------|--------|----------|----------|
| PLAYER_BULLET | 玩家射击 | PLAYER_BULLET | 600 px/s | 10 |
| ENEMY_BULLET | 敌人射击 | ENEMY_BULLET | 300 px/s | 5 |

### 3.2 子弹属性

每个子弹有以下属性：

| 属性 | 描述 | 默认值 |
|------|------|--------|
| `speed` | 飞行速度（px/s） | 600 / 300 |
| `damage` | 命中伤害 | 10 / 5 |
| `direction` | 飞行方向（单位向量） | 由射击系统设置 |
| `lifetime` | 最大存活时间（秒） | 3 |
| `pierce` | 穿透次数（0=不穿透） | 0 |
| `bounces` | 反弹次数（0=不反弹） | 0 |

### 3.3 子弹生命周期

```
生成 → 飞行 → [碰撞/超时] → 销毁（回收）
```

1. **生成**: 从对象池取出，设置位置、方向、速度、伤害
2. **飞行**: 每帧按方向和速度移动
3. **碰撞**: 命中目标 → 触发伤害信号 → 销毁（除非穿透/反弹）
4. **超时**: 超过 `lifetime` 自动销毁
5. **回收**: 回到对象池，等待复用

### 3.4 对象池

为避免频繁创建/销毁子弹（Web 端 GC 压力），使用对象池：

| 参数 | 值 | 说明 |
|------|------|------|
| 玩家子弹池大小 | 150 | 预分配 150 个玩家子弹 |
| 敌人子弹池大小 | 100 | 预分配 100 个敌人子弹 |
| 总子弹上限 | 200 | 同屏最大活跃子弹数 |

- 子弹销毁时回到池中，不释放内存
- 池满时新子弹被忽略（不生成）
- 池中的子弹不可见、不参与碰撞

### 3.5 子弹移动

```gdscript
func _physics_process(delta):
    position += direction * speed * delta
    lifetime_timer -= delta
    if lifetime_timer <= 0:
        deactivate()  # 回到池中
```

- 使用 `CharacterBody2D` 或 `Area2D` + 手动移动
- 碰撞检测由碰撞系统处理
- 碰撞信号 → 弹道系统处理（销毁/穿透/反弹）

### 3.6 穿透与反弹

**穿透**（`pierce > 0`）:
- 命中目标后不销毁，`pierce` 减 1
- `pierce` 归零后下一次命中销毁
- 示例：`pierce = 2` → 穿透 2 个敌人，第 3 次命中销毁

**反弹**（`bounces > 0`）:
- 命中墙壁后不销毁，反射方向，`bounces` 减 1
- 反射角度 = 入射角（镜像反射）
- `bounces` 归零后下一次撞墙销毁

---

## 4. Formulas

子弹移动：
```
position += direction × speed × delta
```

反射角度（反弹）：
```
reflected_direction = direction.bounce(collision_normal)
```

穿透剩余：
```
pierce_remaining = pierce - hits_taken
```

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 子弹池已满 | 忽略新子弹，不生成 |
| 子弹飞出屏幕 | 超过 lifetime 自动回收 |
| 子弹速度极快穿透薄墙 | 使用 CCD 或增加碰撞形状长度 |
| 子弹出生时与发射者重叠 | 出生后 1 帧内不检测碰撞 |
| 穿透子弹命中同一目标两次 | 每次碰撞后短暂忽略该目标（0.1秒） |

## 6. Dependencies

### 依赖
- **碰撞检测**: 子弹的碰撞检测和碰撞信号

### 被依赖
- **射击系统**: 调用弹道系统生成子弹
- **打击反馈**: 子弹命中时触发反馈特效

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 玩家子弹速度 | 600 px/s | 400-1000 | 弹幕感觉：慢→可见，快→弹幕感 |
| 敌人子弹速度 | 300 px/s | 150-500 | 躲避难度 |
| 子弹存活时间 | 3 秒 | 1-5 | 屏幕清理速度 |
| 玩家子弹池 | 150 | 100-300 | 弹幕密度上限 |
| 敌人子弹池 | 100 | 50-200 | 敌人弹幕密度上限 |
| 同屏子弹上限 | 200 | 100-400 | 性能 vs 弹幕密度 |

## 8. Acceptance Criteria

### 功能测试
- [ ] 子弹生成后按正确方向飞行
- [ ] 子弹速度正确（帧率无关）
- [ ] 子弹碰撞目标后触发伤害信号
- [ ] 子弹碰撞后正确销毁（回收到池中）
- [ ] 子弹超过 lifetime 后自动销毁
- [ ] 穿透子弹命中后不销毁，pierce 减 1
- [ ] 反弹子弹撞墙后反射方向

### 性能测试
- [ ] 200 个子弹同时在屏时帧率 ≥ 60fps
- [ ] 对象池正常工作，无内存泄漏
- [ ] 子弹生成/销毁无 GC 峰值

### 边界测试
- [ ] 子弹池满时新子弹不生成
- [ ] 子弹出生帧不与发射者碰撞
- [ ] 穿透子弹不重复命中同一目标
