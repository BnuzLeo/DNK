# 复活币系统 (Revive System)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 生命值系统, 游戏状态管理*
*Depended on by: UI/HUD*

---

## 1. Overview

复活币系统管理玩家死亡后的复活流程：去色 → 倒计时 → 复活币选择 → 复活或退出。它是"再来一局"循环的关键节点 — 给玩家一个"救回来"的机会。

---

## 2. Player Fantasy

玩家感受到的：我死了，但世界变成了灰色。屏幕上出现一个金色的复活币，10 秒倒计时在跳动。我可以选择复活继续战斗，或者放弃重来。

支柱 3（上瘾循环）要求：复活机制减少死亡挫败感，让玩家更容易"再来一局"。支柱 2（即时反馈）要求：去色是瞬间的，倒计时是清晰的。

---

## 3. Detailed Rules

### 3.1 复活流程

```
玩家死亡 → 屏幕去色（1帧）→ 显示复活币界面 → 10秒倒计时 → [复活/退出]
```

### 3.2 复活币

- 玩家每局有 1 个复活币
- 复活币在死亡时显示在屏幕中央
- 复活币是唯一保持颜色的元素（金色 `#FFD700`）
- 其他所有元素去色（灰度）

### 3.3 倒计时

- 10 秒倒计时
- 数字显示在屏幕中央（复活币上方）
- 颜色：Hot Pink（与 Boss 色统一，威胁感）
- 每秒更新一次

### 3.4 复活选择

**选择复活（点击复活币 / 按鼠标左键）：**
- 复活币消失
- 屏幕恢复颜色（1 帧）
- 玩家生命值恢复到 50%
- 玩家有 1.5 秒无敌
- 游戏状态：REVIVING → PLAYING
- 当前房间重新开始（敌人重新刷新）

**选择退出（倒计时结束 / 按 ESC）：**
- 屏幕淡出到黑（1 秒）
- 游戏状态：REVIVING → GAME_OVER
- 返回主菜单

### 3.5 复活币获取

- 每局开始时有 1 个复活币
- MVP 不包含额外获取复活币的机制
- 未来：击败 Boss 或开宝箱获得额外复活币

---

## 4. Formulas

倒计时：
```
remaining_time = 10 - elapsed_time
```

复活后生命值：
```
revive_hp = max_hp × 0.5
```
- 示例：max_hp = 100 → revive_hp = 50

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 倒计时最后 0.5 秒点击复活 | 立刻复活，不等倒计时结束 |
| 没有复活币时死亡 | 直接进入 GAME_OVER，不显示倒计时 |
| 复活期间按暂停 | 暂停被忽略，倒计时继续 |
| 复活后立刻被敌人命中 | 无敌 1.5 秒保护 |
| 复活时房间内有子弹 | 清除所有子弹 |

## 6. Dependencies

### 依赖
- **生命值系统**: 玩家死亡判定、复活后生命值恢复
- **游戏状态管理**: DEAD → REVIVING → PLAYING/GAME_OVER 状态转换

### 被依赖
- **UI/HUD**: 复活币界面显示

---

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 复活币数量 | 1 | 0-3 | 容错率 |
| 倒计时时间 | 10 秒 | 5-15 秒 | 决策压力 |
| 复活后生命值 | 50% | 30-80% | 复活后生存能力 |
| 复活后无敌时间 | 1.5 秒 | 1-3 秒 | 复活后安全窗口 |
| 去色速度 | 1 帧 | 1-10 帧 | 死亡反馈强度 |
