# 玩家移动 (Player Movement)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 碰撞检测*
*Depended on by: 摄像机系统, 近战攻击*

---

## 1. Overview

玩家移动系统处理玩家角色在游戏世界中的位置变化。使用 WASD 键控制 8 方向移动，配合碰撞检测防止穿墙。这是 30 秒核心循环的基础 — 玩家必须能流畅地移动来躲避敌人弹幕和调整射击位置。

---

## 2. Player Fantasy

玩家感受到的：角色像身体的延伸，按下 WASD 的瞬间就开始移动，松开的瞬间就停下。没有加速/减速延迟，没有惯性，没有卡墙感。

支柱 1（弹幕爽感）要求：移动必须零延迟，玩家需要在弹幕中精确走位。任何输入延迟或卡顿都会破坏"行走武器平台"的幻想。

---

## 3. Detailed Rules

### 3.1 输入

- **输入设备**: 键盘 WASD（主要）、方向键（备选）
- **输入**: 4 个方向键的按下/释放状态
- **输出**: 移动方向向量 `Vector2`

### 3.2 移动方式

8 方向移动（允许对角线）：

| 按键组合 | 方向 |
|----------|------|
| W | 上 (0, -1) |
| S | 下 (0, 1) |
| A | 左 (-1, 0) |
| D | 右 (1, 0) |
| W+D | 右上 (1, -1).normalized() |
| W+A | 左上 (-1, -1).normalized() |
| S+D | 右下 (1, 1).normalized() |
| S+A | 左下 (-1, 1).normalized() |
| 无 | 静止 (0, 0) |

### 3.3 移动计算

```gdscript
func get_move_direction() -> Vector2:
    var direction = Vector2.ZERO
    direction.x = Input.get_axis("move_left", "move_right")  # A/D
    direction.y = Input.get_axis("move_up", "move_down")      # W/S
    return direction.normalized()
```

- 对角线移动归一化为单位向量（防止对角线速度 ×√2）
- 方向向量 × 移动速度 = 实际速度

### 3.4 碰撞处理

- 使用 Godot 的 `CharacterBody2D` 节点
- `move_and_slide()` 处理与墙壁的碰撞
- 碰撞时沿墙滑动（不卡住）
- 不穿透任何 WALL 层物体

### 3.5 状态限制

| 游戏状态 | 移动是否激活 |
|----------|-------------|
| MAIN_MENU | 否 |
| PLAYING | 是 |
| PAUSED | 否 |
| DEAD | 否 |
| REVIVING | 否 |
| GAME_OVER | 否 |

---

## 4. Formulas

移动速度：
```
velocity = move_direction × move_speed
```
- `move_direction`: 归一化的方向向量
- `move_speed`: 移动速度（像素/秒）

实际位移（每帧）：
```
position_change = velocity × delta
```
- `delta`: 帧间隔时间（秒）

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 同时按下 W 和 S（上下抵消） | 归一化后为 (0, 0)，角色静止 |
| 同时按 3 个键（如 W+A+D） | 归一化处理，W 方向生效 |
| 角色卡在墙壁里 | `move_and_slide()` 自动推开 |
| 高帧率/低帧率差异 | 使用 `delta` 时间补偿，帧率无关 |
| 移动速度为 0 | 角色静止，不触发碰撞 |

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 移动速度 | 200 px/s | 100-400 px/s | 操控感：慢→策略性，快→爽快感 |
| 加速度 | 即时 | 即时-0.2秒 | 响应感：即时→零延迟，有加速→更物理 |
| 减速度 | 即时 | 即时-0.2秒 | 停止感：即时→精确，有惯性→滑动感 |
| 碰撞滑动 | 是 | 是/否 | 沿墙滑动 vs 完全停止 |

## 8. Acceptance Criteria

### 功能测试
- [ ] 按 WASD 角色正确移动
- [ ] 对角线移动速度与直线一致（归一化）
- [ ] 松开按键角色立即停止
- [ ] 碰到墙壁时角色停止，不穿透
- [ ] 沿墙滑动正常工作
- [ ] PLAYING 状态下移动激活
- [ ] 其他状态下移动不激活

### 性能测试
- [ ] 移动计算耗时 < 0.1ms
- [ ] 与碰撞系统配合无性能问题

### 集成测试
- [ ] 摄像机正确跟随玩家移动
- [ ] 移动不影响瞄准方向
- [ ] 移动时射击正常工作（边走边射）
