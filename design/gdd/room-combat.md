# 房间制战斗 (Room-Based Combat)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 关卡/楼层系统, 敌人 AI, 游戏状态管理*
*Depended on by: UI/HUD*

---

## 1. Overview

房间制战斗系统管理每个战斗房间的生命周期：进入 → 敌人刷新 → 战斗 → 清空 → 奖励 → 开门。它是核心循环"再来一个房间"的结构载体。

---

## 2. Player Fantasy

玩家感受到的：每进入一个新房间，门在身后关上，敌人从四面八方涌来。清空房间后，门打开，奖励出现，我知道下一个房间在等着我。

支柱 3（上瘾循环）要求：房间节奏是"紧张→释放→紧张"的循环。每个房间都是独立的战斗单元，清房后的成就感推动"再来一个"。

---

## 3. Detailed Rules

### 3.1 房间生命周期

```
进入房间 → 门关闭 → 敌人刷新 → 战斗中 → 所有敌人死亡 → 奖励生成 → 门打开 → 等待玩家进入下一个房间
```

### 3.2 房间配置

每个房间有以下配置：

| 属性 | 描述 | MVP 默认值 |
|------|------|-----------|
| `room_size` | 房间尺寸 | 480×320 px |
| `enemy_list` | 敌人类型和数量 | 3-5 个 CHASER + 1-2 个 SHOOTER |
| `spawn_delay` | 敌人生成间隔 | 0.5 秒 |
| `reward_type` | 奖励类型 | 无（MVP 无强化系统） |
| `door_position` | 门的位置 | 房间对侧 |

### 3.3 敌人刷新

- 玩家进入房间后，门关闭
- 延迟 0.5 秒后开始刷新敌人
- 每 0.5 秒刷新一个敌人
- 刷新位置：房间内随机位置，不与玩家重叠
- 刷新时敌人有 0.5 秒无敌

### 3.4 清房判定

当房间内所有敌人生命值归零并从场景移除后：
- 触发 `room_cleared` 信号
- 等待 0.5 秒（奖励动画时间）
- 门打开
- 玩家可以进入下一个房间

### 3.5 门机制

- 门在房间进入时关闭（碰撞启用）
- 门在房间清空后打开（碰撞禁用）
- 门的视觉：关闭时发光，打开时暗淡
- 玩家接触打开的门 → 进入下一个房间

### 3.6 房间切换

- 玩家接触门 → 触发 `room_enter` 信号
- 关卡系统加载下一个房间
- 玩家位置重置到新房间入口
- 新房间的敌人开始刷新

---

## 4. Formulas

敌人数量递增：
```
enemy_count = base_count + (current_room - 1)
```
- `base_count`: 基础敌人数量（3）
- 示例：房间 3 → 5 个敌人

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 玩家在敌人刷新期间死亡 | 停止刷新，进入死亡流程 |
| 敌人在刷新动画期间被子弹命中 | 刷新无敌期间不受伤 |
| 玩家尝试在战斗中离开房间 | 门关闭，无法离开 |
| 所有敌人死亡但 `room_cleared` 未触发 | 检查敌人是否全部从场景移除 |
| 房间切换时有子弹在飞 | 清除所有活跃子弹 |

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 房间尺寸 | 480×320 | 320×240 - 640×480 | 战斗空间 |
| 敌人生成间隔 | 0.5 秒 | 0.3-1 秒 | 刷新节奏 |
| 清房后延迟 | 0.5 秒 | 0-1 秒 | 奖励动画时间 |
| 门关闭延迟 | 0 秒 | 0-0.5 秒 | 进入房间后的缓冲 |
| 刷新无敌时间 | 0.5 秒 | 0-1 秒 | 防止瞬间秒杀 |
