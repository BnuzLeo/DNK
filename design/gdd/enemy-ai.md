# 敌人 AI (Enemy AI)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 生命值系统, 碰撞检测*
*Depended on by: Boss 战, 房间制战斗*

---

## 1. Overview

敌人 AI 系统控制游戏中所有敌人的行为：移动模式、攻击模式、目标选择。不同类型的敌人有不同的 AI 模式，为战斗提供多样性和挑战性。

---

## 2. Player Fantasy

玩家感受到的：敌人不是傻站着的靶子，它们会追你、会射击、会包围你。但它们的行为是可读的、可预测的 — 玩家可以通过观察学会躲避模式。

支柱 1（弹幕爽感）要求：敌人射击增加弹幕密度。支柱 2（即时反馈）要求：敌人行为有清晰的"告诉"（攻击前的预示）。支柱 3（上瘾循环）要求：敌人难度递增，推动"再来一个房间"。

---

## 3. Detailed Rules

### 3.1 敌人类型

| 类型 | 移动模式 | 攻击模式 | 生命值 | 数量/房间 |
|------|----------|----------|--------|-----------|
| CHASER | 追踪玩家 | 接触伤害 | 20 | 3-5 |
| SHOOTER | 保持距离 | 远程射击 | 30 | 2-3 |
| TANK | 缓慢追踪 | 接触伤害 | 80 | 1-2 |
| SWARM | 群体追踪 | 接触伤害 | 10 | 5-8 |

### 3.2 AI 状态机

每个敌人有一个简单状态机：

```
IDLE → CHASE → ATTACK → [DEAD]
```

- **IDLE**: 刚生成，等待 0.5 秒后进入 CHASE
- **CHASE**: 执行移动模式
- **ATTACK**: 执行攻击模式（射击或接触伤害）
- **DEAD**: 生命值归零，播放死亡动画，从场景移除

### 3.3 移动模式

**CHASER（追踪）:**
- 朝玩家位置移动
- 速度：100 px/s
- 碰到墙壁时绕行

**SHOOTER（保持距离）:**
- 与玩家保持 150-200px 距离
- 距离太近 → 后退
- 距离太远 → 前进
- 速度：80 px/s

**TANK（缓慢追踪）:**
- 朝玩家位置移动
- 速度：50 px/s
- 不绕行，撞墙停止

**SWARM（群体追踪）:**
- 朝玩家位置移动
- 速度：120 px/s
- 群体间有微小随机偏移（不完全重叠）

### 3.4 攻击模式

**接触伤害:**
- 敌人碰到玩家时触发伤害
- 伤害值：10
- 有 1 秒冷却（防止连续伤害）

**远程射击:**
- 每 1.5-2 秒发射 1 发子弹
- 子弹朝玩家方向
- 子弹速度：300 px/s
- 子弹伤害：5
- 射击前有 0.3 秒"告诉"（角色闪烁或停顿）

### 3.5 生成规则

- 敌人在房间进入时生成
- 生成位置：房间内随机位置，不与玩家重叠
- 生成间隔：每 0.5 秒生成一个（不全部同时出现）
- 生成时有 0.5 秒无敌（防止瞬间被子弹秒杀）

### 3.6 目标选择

- 所有敌人默认追踪玩家
- 如果有多个玩家（未来多人），追踪最近的玩家

## 4. Formulas

追踪方向：
```
direction = (player_position - enemy_position).normalized()
velocity = direction × move_speed
```

射击方向：
```
direction = (player_position - enemy_position).normalized()
```

保持距离：
```
distance = enemy_position.distance_to(player_position)
if distance < min_distance:
    move away from player
elif distance > max_distance:
    move toward player
else:
    stay still
```

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 敌人卡在墙角 | 碰撞系统处理滑动，AI 随机方向偏移 |
| 敌人重叠 | 生成时检测重叠，偏移位置 |
| 玩家死亡后敌人行为 | 停止移动和攻击，等待状态切换 |
| 敌人在攻击"告诉"期间被杀死 | 立即取消攻击，进入死亡流程 |
| 所有敌人被消灭 | 触发 `room_cleared` 信号 |

## 6. Dependencies

### 依赖
- **生命值系统**: 敌人血量管理、死亡判定
- **碰撞检测**: 敌人与玩家/墙壁的碰撞

### 被依赖
- **Boss 战**: Boss 使用扩展的 AI 状态机
- **房间制战斗**: 敌人生成、消灭检测

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| CHASER 速度 | 100 px/s | 60-200 | 追踪压力 |
| SHOOTER 速度 | 80 px/s | 50-150 | 机动性 |
| TANK 速度 | 50 px/s | 30-100 | 压迫感 |
| SWARM 速度 | 120 px/s | 80-200 | 群体压力 |
| 射击间隔 | 1.5-2 秒 | 0.5-3 秒 | 弹幕密度 |
| 射击"告诉"时间 | 0.3 秒 | 0.1-0.5 秒 | 可读性 |
| 接触伤害 | 10 | 5-20 | 近身威胁 |
| 接触伤害冷却 | 1 秒 | 0.5-2 秒 | 防止连续伤害 |
| 生成无敌时间 | 0.5 秒 | 0-1 秒 | 防止瞬间秒杀 |

## 8. Acceptance Criteria

### 功能测试
- [ ] CHASER 类型敌人追踪玩家移动
- [ ] SHOOTER 类型敌人保持距离并射击
- [ ] TANK 类型敌人缓慢追踪
- [ ] SWARM 类型敌人群体追踪
- [ ] 敌人射击子弹朝玩家方向
- [ ] 射击前有 0.3 秒"告诉"
- [ ] 接触伤害正确应用
- [ ] 敌人死亡后从场景移除
- [ ] 所有敌人消灭后触发 `room_cleared` 信号

### 边界测试
- [ ] 敌人不与墙壁重叠
- [ ] 敌人生成时不与玩家重叠
- [ ] 玩家死亡后敌人停止行动
- [ ] 敌人在攻击"告诉"期间被杀死取消攻击

### 集成测试
- [ ] 敌人子弹正确命中玩家
- [ ] 玩家子弹正确命中敌人
- [ ] 敌人生命值归零时正确死亡
