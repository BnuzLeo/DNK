# UI/HUD (界面与抬头显示)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Presentation Layer*
*Depends on: 生命值系统, Boss 战, 复活币系统, 游戏状态管理*
*Depended on by: —*

---

## 1. Overview

UI/HUD 系统管理所有玩家界面：主菜单、游戏内 HUD、复活界面、暂停菜单、游戏结束界面。它是玩家与游戏状态之间的桥梁 — 让玩家随时知道"我现在在哪，状态如何"。

---

## 2. Player Fantasy

玩家感受到的：HUD 简洁但信息充分。血条在左上角，Boss 血条在顶部。复活时屏幕变成灰色，金色复活币在中央。界面不会抢走战斗的注意力，但关键时刻（死亡、Boss）有明确的视觉语言。

支柱 2（即时反馈）要求：血量变化即时可见。支柱 4（像素酷炫）要求：UI 使用像素字体，与游戏风格统一。

---

## 3. Detailed Rules

### 3.1 游戏内 HUD

**玩家血条：**
- 位置：左上角（10, 10）
- 大小：100×12 px
- 颜色：满血绿色 `#00FF88`，低血红色 `#FF0000`
- 低血阈值：30% HP 以下变红
- 背景：半透明黑色 `#00000080`
- 边框：1px 白色

**Boss 血条：**
- 位置：屏幕顶部居中
- 大小：300×16 px
- 颜色：Hot Pink `#FF69B4`
- 背景：半透明黑色
- Boss 名称：血条上方，白色像素字体
- 仅在 Boss 房间显示

**复活币显示：**
- 位置：血条右侧（120, 10）
- 图标：16×16 金色硬币
- 数量：数字显示（MVP 固定为 1）
- 没有复活币时图标变灰

**房间进度：**
- 位置：右上角（-10, 10，右对齐）
- 显示：`房间 X/Y`
- 颜色：白色像素字体

### 3.2 复活界面

玩家死亡后显示：
- 整个屏幕去色（灰度滤镜）
- 屏幕中央：金色复活币图标（64×64）
- 复活币上方：倒计时数字（Hot Pink，48px 字体）
- 复活币下方：提示文字"点击复活 / ESC 退出"（白色，16px）
- 倒计时从 10 到 0，每秒更新

### 3.3 主菜单

- 标题：游戏名称，居中，大号像素字体
- 按钮：`开始游戏` / `退出`
- 背景：游戏内战斗画面循环播放（5-8 秒循环）
- 按钮样式：像素风格，hover 时发光

### 3.4 暂停菜单

- 触发：按 ESC（在 PLAYING 状态时）
- 半透明黑色遮罩覆盖全屏
- 居中显示：`继续` / `重新开始` / `退出`
- 游戏画面在遮罩下可见但变暗

### 3.5 游戏结束界面

- 屏幕淡出到黑（1 秒）
- 显示：`游戏结束` + 本次击杀数
- 按钮：`重新开始` / `返回主菜单`
- 2 秒后可点击按钮（防误触）

### 3.6 楼层过渡

- Boss 死亡后屏幕渐黑（0.5 秒）
- 显示：`第 X 层 完成`（白色大字，1 秒）
- 然后渐黑过渡到下一层

### 3.7 UI 层级

```
CanvasLayer 0: 游戏世界（玩家、敌人、子弹）
CanvasLayer 10: HUD（血条、Boss 血条、房间进度）
CanvasLayer 20: 复活界面（去色 + 复活币 + 倒计时）
CanvasLayer 30: 暂停菜单
CanvasLayer 40: 游戏结束
CanvasLayer 50: 主菜单
```

## 4. Formulas

血条颜色插值：
```
if hp_ratio > 0.3:
    color = lerp(Color.RED, Color.GREEN, (hp_ratio - 0.3) / 0.7)
else:
    color = Color.RED
```

血条宽度：
```
bar_width = max_width × (current_hp / max_hp)
```

去色 shader 参数：
```
gray = dot(rgb, vec3(0.299, 0.587, 0.114))
output = mix(original_color, vec3(gray), desaturate_amount)
```
- `desaturate_amount`: 0.0 = 原色，1.0 = 完全灰度

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 血量为 0 但死亡流程未开始 | 血条显示为空，等待死亡流程 |
| Boss 入场动画期间 | Boss 血条不显示，入场结束后显示 |
| 复活界面时按暂停 | 暂停被忽略，倒计时继续 |
| 主菜单背景播放时游戏状态 | 背景是预录制画面，不与游戏逻辑交互 |
| 多个 UI 层同时显示 | 按 CanvasLayer 层级正确遮挡 |
| 窗口大小变化 | UI 元素使用锚点定位，自动适应 |

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 血条宽度 | 100 px | 80-200 | 信息可见性 |
| Boss 血条宽度 | 300 px | 200-400 | Boss 血量感知 |
| 低血阈值 | 30% | 20-40% | 危险感知时机 |
| 去色速度 | 1 帧 | 1-10 | 死亡冲击感 |
| 复活倒计时 | 10 秒 | 5-15 | 决策压力 |
| 游戏结束延迟 | 2 秒 | 1-3 | 防误触 |
| 楼层过渡文字时间 | 1 秒 | 0.5-2 | 节奏感 |
