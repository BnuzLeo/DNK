# 生命值系统 (Health System)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Core Layer*
*Depends on: 游戏状态管理, 碰撞检测*
*Depended on by: 敌人 AI, 射击系统, Boss 战, 复活币系统, 打击反馈, UI/HUD, 近战攻击*

---

## 1. Overview

生命值系统管理游戏中所有可受伤实体（玩家、敌人、Boss）的生命值。它处理伤害计算、死亡判定、无敌帧、以及死亡触发的状态转换。这是战斗系统的核心 — 没有生命值，就没有战斗。

---

## 2. Player Fantasy

玩家感受到的：每一发子弹命中都有意义（敌人血量在减少），自己被打中时有明确的反馈（受伤闪烁 + 飘字），击败敌人时有成就感（敌人爆炸死亡）。

支柱 2（即时反馈）要求：伤害数字必须在命中瞬间出现，不能有延迟。死亡必须有明确的视觉确认（敌人爆炸、屏幕震动）。

---

## 3. Detailed Rules

### 3.1 生命值属性

每个可受伤实体都有以下属性：

| 属性 | 描述 | 默认值（玩家） | 默认值（普通敌人） | 默认值（Boss） |
|------|------|----------------|-------------------|----------------|
| `max_hp` | 最大生命值 | 100 | 20-50 | 500 |
| `current_hp` | 当前生命值 | 100 | 20-50 | 500 |
| `armor` | 护甲（减伤百分比） | 0 | 0 | 0 |
| `invincible` | 是否处于无敌状态 | false | false | false |
| `invincible_duration` | 无敌帧持续时间 | 1.5 秒 | 0 秒 | 0 秒 |

### 3.2 伤害计算

```
实际伤害 = 基础伤害 × (1 - armor / 100)
最终生命值 = max(0, current_hp - 实际伤害)
```

- `armor` 范围：0-80（护甲最多减伤 80%）
- `基础伤害` 来自子弹/近战的 `damage` 属性
- 伤害最低为 1（即使有护甲，也不能完全免疫）

### 3.3 无敌帧

玩家受伤后进入无敌状态：
- 持续时间：1.5 秒
- 视觉表现：角色闪烁（每 0.1 秒切换可见/不可见）
- 无敌期间不接收新的伤害
- 无敌结束后恢复正常状态

敌人和 Boss 没有无敌帧（允许弹幕持续输出）。

### 3.4 死亡判定

当 `current_hp ≤ 0` 时：

**玩家死亡：**
1. 触发 `player_died` 信号
2. 游戏状态管理：PLAYING → DEAD
3. 屏幕去色（1 帧）
4. 进入复活流程（由复活币系统处理）

**普通敌人死亡：**
1. 触发 `enemy_died(enemy)` 信号
2. 播放死亡动画（爆炸特效）
3. 显示伤害飘字
4. 屏幕震动
5. 从场景中移除

**Boss 死亡：**
1. 触发 `boss_died(boss)` 信号
2. 播放特殊死亡动画
3. 屏幕震动（更强烈）
4. 触发关卡推进（由关卡系统处理）

### 3.5 治疗

玩家可以被治疗：
- 治疗量不能超过 `max_hp`
- 治疗时显示绿色飘字
- 治疗时播放恢复特效

## 4. Formulas

### 伤害计算
```
实际伤害 = base_damage × (1 - armor / 100)
```
- `base_damage`: 子弹/近战的基础伤害值
- `armor`: 目标护甲值（0-80）
- 示例：基础伤害 10，护甲 20 → 实际伤害 = 10 × (1 - 20/100) = 8

### 生命值变化
```
new_hp = clamp(current_hp ± amount, 0, max_hp)
```
- 正数 = 伤害，负数 = 治疗
- `clamp` 确保不超出 [0, max_hp] 范围

### 无敌帧时间
```
invincible_until = current_time + invincible_duration
```

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 多个伤害同时命中玩家 | 无敌帧生效后忽略后续伤害，只处理第一次 |
| 伤害值为 0 或负数 | 忽略，不触发任何效果 |
| 护甲超过 80 | 限制为 80，伤害最低为 1 |
| 治疗时已满血 | 忽略治疗，不触发特效 |
| Boss 被一击秒杀 | 正常处理死亡流程，不特殊处理 |
| 敌人在死亡动画中再次被击中 | 忽略，死亡动画期间不处理新伤害 |

## 6. Dependencies

### 依赖
- **游戏状态管理**: 读取状态判断是否处理伤害（PAUSED/DEAD 状态不处理）
- **碰撞检测**: 接收碰撞信号，触发伤害计算

### 被依赖
- **敌人 AI**: 读取敌人生命值判断是否死亡
- **射击系统**: 子弹携带 `damage` 属性
- **Boss 战**: Boss 生命值管理、阶段转换
- **复活币系统**: 玩家死亡时触发复活流程
- **打击反馈**: 伤害数字显示、命中特效
- **UI/HUD**: 玩家/敌人血条显示
- **近战攻击**: 近战携带 `damage` 属性

---

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 玩家最大生命值 | 100 | 50-200 | 游戏难度：低→更紧张，高→更宽松 |
| 普通敌人生命值 | 20-50 | 10-100 | 战斗节奏：低→一击秒杀，高→需要多发子弹 |
| Boss 生命值 | 500 | 200-1000 | Boss 战时长 |
| 玩家无敌帧 | 1.5 秒 | 0.5-3 秒 | 容错率：短→硬核，长→宽松 |
| 护甲上限 | 80 | 50-90 | 减伤上限 |
| 最低伤害 | 1 | 1 | 保证不能完全免疫伤害 |
