# 瞄准系统 (Aiming System)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Core Layer*
*Depends on: 游戏状态管理*
*Depended on by: 射击系统*

---

## 1. Overview

瞄准系统负责将鼠标的屏幕位置转换为游戏世界中的射击方向。玩家通过鼠标控制射击方向，系统计算从玩家位置到鼠标位置的方向向量，传递给射击系统生成子弹。

这是"鼠标瞄准 + 射击"核心操作的第一步。简单直接 — 玩家鼠标指向哪里，子弹就飞向哪里。

---

## 2. Player Fantasy

玩家感受到的：鼠标就是枪口，指哪打哪。没有辅助瞄准、没有子弹偏移、没有延迟。手指移动的瞬间，射击方向就变了。

支柱 1（弹幕爽感）要求：瞄准必须零延迟，射击方向必须精确跟随鼠标。任何输入延迟都会破坏"行走武器平台"的幻想。

---

## 3. Detailed Rules

### 3.1 输入处理

- **输入设备**: 鼠标（主要）、触屏（可选）
- **输入**: 鼠标在屏幕上的位置
- **输出**: 从玩家位置到鼠标位置的单位方向向量 `Vector2`

### 3.2 方向计算

```gdscript
func get_aim_direction() -> Vector2:
    var mouse_pos = get_global_mouse_position()
    var direction = (mouse_pos - player.global_position).normalized()
    return direction
```

- 方向向量是单位向量（长度为 1）
- 方向始终从玩家位置指向鼠标位置
- 如果鼠标在玩家正上方，方向为 (0, -1)
- 如果鼠标在玩家右下方，方向为 (1, 1).normalized()

### 3.3 状态限制

| 游戏状态 | 瞄准是否激活 |
|----------|-------------|
| MAIN_MENU | 否 |
| PLAYING | 是 |
| PAUSED | 否（锁定最后方向） |
| DEAD | 否 |
| REVIVING | 否 |
| GAME_OVER | 否 |

### 3.4 视觉反馈

- 玩家角色朝向跟随瞄准方向（精灵翻转或旋转）
- 可选：显示准星（鼠标位置的小十字）
- 可选：显示射击方向线（从玩家到鼠标的虚线）

---

## 4. Formulas

方向向量计算：
```
direction = (mouse_position - player_position).normalized()
```
- `mouse_position`: 鼠标在世界坐标系中的位置
- `player_position`: 玩家在世界坐标系中的位置
- `.normalized()`: 归一化为单位向量

角度计算（用于精灵朝向）：
```
angle = atan2(direction.y, direction.x)
```

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 鼠标在玩家正中心（距离为 0） | 保持上一帧的方向，不更新 |
| 鼠标移出游戏窗口 | 使用窗口边缘的位置 |
| 游戏暂停时移动鼠标 | 不更新方向，锁定最后方向 |
| 高 DPI 屏幕 | Godot 自动处理，无需额外适配 |

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 瞄准平滑度 | 0（无平滑） | 0-0.3 | 0=即时跟随，0.3=有延迟感 |
| 角色朝向跟随速度 | 即时 | 即时/0.1秒 | 角色精灵翻转的速度 |
| 显示准星 | 否 | 是/否 | 辅助瞄准 |
| 显示方向线 | 否 | 是/否 | 调试用 |

## 8. Acceptance Criteria

### 功能测试
- [ ] 鼠标移动时瞄准方向正确更新
- [ ] 方向向量是从玩家指向鼠标
- [ ] 方向向量是单位向量（长度为 1）
- [ ] PLAYING 状态下瞄准激活
- [ ] PAUSED/DEAD/REVIVING 状态下瞄准不激活
- [ ] 角色精灵朝向跟随瞄准方向

### 边界测试
- [ ] 鼠标在玩家正中心时保持上一帧方向
- [ ] 鼠标移出窗口时使用边缘位置
- [ ] 暂停时鼠标移动不影响方向

### 集成测试
- [ ] 瞄准方向正确传递给射击系统
- [ ] 射击系统使用瞄准方向生成子弹
