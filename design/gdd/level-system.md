# 关卡/楼层系统 (Level/Floor System)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 游戏状态管理*
*Depended on by: Boss 战, 房间制战斗, UI/HUD*

---

## 1. Overview

关卡/楼层系统管理游戏的结构：楼层 → 房间序列 → Boss 房间。它控制玩家的推进进度、楼层切换、以及胜利/失败条件。

---

## 2. Player Fantasy

玩家感受到的：我在一层一层地推进，每层都比上一层难，每层末尾都有一个 Boss 等着我。清完一个房间后，我知道下一个房间在等着我。

支柱 3（上瘾循环）要求：楼层结构清晰，玩家知道自己的进度，有"再来一个房间"的动力。

---

## 3. Detailed Rules

### 3.1 楼层结构

| 楼层 | 房间数 | 敌人难度 | Boss |
|------|--------|----------|------|
| 第 1 层 | 3 个普通房间 + 1 个 Boss 房 | 基础 | Boss 1 |
| 第 2 层 | 3 个普通房间 + 1 个 Boss 房 | 中等 | Boss 2 |
| 第 3 层 | 3 个普通房间 + 1 个 Boss 房 | 困难 | Boss 3 |

MVP 只有 1 层（3 个普通房间 + 1 个 Boss 房）。

### 3.2 房间类型

| 类型 | 描述 | 敌人配置 |
|------|------|----------|
| NORMAL | 普通战斗房间 | 3-5 个普通敌人 |
| BOSS | Boss 战斗房间 | 1 个 Boss |
| TREASURE | 奖励房间（MVP 不包含） | 无敌人 |

### 3.3 楼层推进流程

```
进入楼层 → 房间 1 → 房间 2 → 房间 3 → Boss 房间 → 下一层（或胜利）
```

- 每个房间清空后，门打开，玩家进入下一个房间
- Boss 房间清空后，楼层完成
- 最后一层 Boss 清空后，游戏胜利

### 3.4 房间序列

每个楼层的房间序列在进入楼层时生成：
- MVP：固定序列（房间 1 → 房间 2 → 房间 3 → Boss）
- 未来：随机序列（从房间池中随机选择）

### 3.5 进度追踪

| 变量 | 描述 |
|------|------|
| `current_floor` | 当前楼层（1-3） |
| `current_room` | 当前房间（1-4） |
| `rooms_cleared` | 已清空房间数 |
| `total_rooms` | 总房间数 |

---

## 4. Formulas

房间难度递增：
```
enemy_count = base_count + (current_floor - 1) × 2
enemy_hp_multiplier = 1 + (current_floor - 1) × 0.3
```
- `base_count`: 基础敌人数量（3）
- 示例：第 2 层 → 5 个敌人，血量 ×1.3

---

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 玩家在 Boss 房间死亡 | 复活后从 Boss 房间重新开始 |
| 最后一层 Boss 清空 | 触发游戏胜利 |
| 房间清空但门还没开 | 延迟 0.5 秒开门（奖励动画时间） |
| 玩家尝试回到上一个房间 | 不允许，只能前进 |

## 6. Dependencies

### 依赖

### 被依赖

- **UI/HUD**: 显示当前楼层/房间进度

---

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 每层房间数 | 3+1 Boss | 2-5+1 | 每层时长 |
| MVP 层数 | 1 | 1-3 | 游戏总时长 |
| 敌人数量递增 | +2/层 | +1-+3 | 难度曲线 |
| 敌人血量递增 | +30%/层 | +20-+50% | 难度曲线 |
| 房间间延迟 | 0.5 秒 | 0-1 秒 | 节奏感 |
