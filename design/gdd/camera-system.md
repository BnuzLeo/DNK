# 摄像机系统 (Camera System)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Presentation Layer*
*Depends on: 玩家移动*
*Depended on by: 打击反馈*

---

## 1. Overview

摄像机系统控制玩家视角：跟随玩家、屏幕震动、Boss 入场拉远。它是视觉体验的框架 — 所有战斗爽感都通过它传递给玩家。

---

## 2. Player Fantasy

玩家感受到的：摄像机紧跟着我移动，但不会让我觉得被限制。开枪命中时屏幕在震动，Boss 出现时摄像机拉远让我看到全貌。摄像机是我感受战斗节奏的窗口。

支柱 2（即时反馈）要求：震动是即时的，跟随是流畅的。支柱 1（弹幕爽感）要求：弹幕密集时摄像机不会抖到看不清。

---

## 3. Detailed Rules

### 3.1 跟随模式

- 使用 Godot Camera2D 节点
- 跟随目标：玩家 CharacterBody2D
- 跟随模式：`Camera2D.SMOOTH`
- 平滑速度：5.0（`position_smoothing_speed`）
- 摄像机锚点：玩家中心

### 3.2 摄像机边界

- 每个房间定义摄像机边界（Rect2）
- 摄像机不会超出房间边界
- 进入新房间时，摄像机边界瞬间切换到新房间的边界
- 房间切换时摄像机无过渡动画（瞬切，与房间切换节奏一致）

### 3.3 屏幕震动

屏幕震动由多个来源触发：

| 触发源 | 震动强度 | 持续时间 | 衰减 |
|--------|----------|----------|------|
| 玩家命中敌人 | 2.0 | 0.1 秒 | 线性 |
| 玩家受伤 | 4.0 | 0.15 秒 | 线性 |
| Boss 命中 | 5.0 | 0.2 秒 | 线性 |
| Boss 死亡 | 8.0 | 0.5 秒 | 指数 |
| 敌人死亡 | 1.0 | 0.05 秒 | 线性 |

### 3.4 震动实现

- 震动方向：随机单位向量
- 每帧更新：`offset = random_direction × intensity × remaining_ratio`
- 多个震动叠加时取最大值（不累加，防止过度震动）
- 震动不影响摄像机的实际位置，只影响 offset

### 3.5 Boss 入场

- 进入 Boss 房间时，摄像机拉远（zoom 从 1.0 到 0.7）
- 拉远过程 1 秒，使用 ease_out 缓动
- Boss 出现后保持 0.7 zoom 2 秒
- 然后缩回 1.0（0.5 秒，ease_in）
- 战斗开始后 zoom 固定为 1.0

### 3.6 摄像机限制

- 最小 zoom：0.5（防止过远看不清像素）
- 最大 zoom：2.0（防止过近只看到局部）
- MVP 固定 zoom 1.0，Boss 入场时例外

## 4. Formulas

震动偏移：
```
offset_x = random_range(-1, 1) × shake_intensity × decay_ratio
offset_y = random_range(-1, 1) × shake_intensity × decay_ratio
```

震动衰减：
```
linear_decay:    decay_ratio = remaining_time / total_duration
exponential_decay: decay_ratio = (remaining_time / total_duration)^2
```

多个震动叠加：
```
final_offset = max(shake_a.offset, shake_b.offset)  # 逐分量取最大值
```

Boss 入场 zoom：
```
zoom = lerp(1.0, 0.7, ease_out(progress))
```

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 玩家在房间边界移动 | 摄像机被边界约束，玩家可能偏离屏幕中心 |
| 房间切换时震动未结束 | 震动立即重置，新房间不继承旧震动 |
| Boss 入场期间玩家死亡 | 入场动画继续，死亡流程在入场结束后触发 |
| 同时触发多个震动源 | 取最大值，不累加 |
| 摄像机跟随速度过快导致晕动 | 平滑速度 5.0 是保守值，可通过调试调整 |

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 跟随平滑速度 | 5.0 | 3.0-10.0 | 跟随延迟感 |
| 玩家命中震动强度 | 2.0 | 1.0-5.0 | 命中反馈感 |
| 玩家受伤震动强度 | 4.0 | 2.0-8.0 | 受伤反馈感 |
| Boss 死亡震动强度 | 8.0 | 5.0-15.0 | Boss 击败成就感 |
| Boss 入场 zoom | 0.7 | 0.5-0.9 | Boss 入场压迫感 |
| Boss 入场拉远时间 | 1.0 秒 | 0.5-2.0 | 入场戏剧感 |
