# 打击反馈 (Hit Feedback)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Presentation Layer*
*Depends on: 射击系统, 生命值系统, 摄像机系统*
*Depended on by: 粒子特效*

---

## 1. Overview

打击反馈系统管理所有战斗中的感官反馈：命中停顿、伤害飘字、屏幕震动、敌人闪烁。它是"射击爽感"的最后一环 — 让玩家知道"我打中了，而且打得很爽"。

---

## 2. Player Fantasy

玩家感受到的：子弹命中敌人时，敌人闪白、屏幕微震、伤害数字飞出来。Boss 被打中时反馈更强烈。每一发子弹都有存在感，射击本身就是奖励。

支柱 1（弹幕爽感）要求：密集弹幕命中时反馈叠加但不混乱。支柱 2（即时反馈）要求：命中后 1 帧内看到反馈。

---

## 3. Detailed Rules

### 3.1 命中停顿 (Hit Stop)

- 子弹命中敌人时，游戏暂停 1-3 帧
- 命中普通敌人：1 帧（~16ms）
- 命中 Boss：2 帧（~32ms）
- 击杀敌人：3 帧（~48ms）
- 实现方式：`Engine.time_scale = 0` 持续 N 帧后恢复 `= 1`
- 多个命中同帧触发时，取最长停顿

### 3.2 敌人闪烁

- 命中时敌人变白 1 帧
- 实现方式：设置 `modulate = Color.WHITE`，1 帧后恢复原色
- 使用 Godot 的 `flash` shader 或直接 modulate
- 击杀时闪烁 3 次（每 2 帧切换）

### 3.3 伤害飘字 (Damage Numbers)

- 子弹命中时在命中位置生成伤害数字
- 数字颜色：
  - 普通伤害：白色 `#FFFFFF`
  - 暴击伤害：橙色 `#FF8800`
  - Boss 伤害：Hot Pink `#FF69B4`
- 数字行为：
  - 生成时向上漂浮（30 px/s）
  - 水平方向随机偏移（±10px）
  - 存活 0.5 秒后淡出消失
  - 字体大小：普通 12px，暴击 16px，Boss 14px

### 3.4 命中闪 (Hit Flash)

- 子弹命中位置生成一个小白色闪光
- 大小：8×8 px
- 持续：2 帧
- 颜色：白色 → 透明（快速淡出）

### 3.5 击杀反馈

敌人死亡时：
- 敌人闪烁 3 次（白/原色，每 2 帧）
- 然后缩小到 0 并消失（0.2 秒）
- 屏幕震动 1.0 强度，0.05 秒
- 视觉上"炸开"的感觉

### 3.6 反馈层级

不同严重程度的事件有不同强度的反馈：

| 事件 | 停顿 | 闪烁 | 震动 | 飘字 |
|------|------|------|------|------|
| 命中普通敌人 | 1 帧 | 白 1 帧 | 2.0 | 白色数字 |
| 击杀普通敌人 | 3 帧 | 白×3 | 1.0 | 白色数字 |
| 命中 Boss | 2 帧 | 白 1 帧 | 5.0 | Pink 数字 |
| 击杀 Boss | 5 帧 | 白×5 | 8.0 | Pink 大数字 |
| 玩家受伤 | — | 玩家闪红 | 4.0 | 红色数字 |

## 4. Formulas

伤害飘字位置：
```
text_position = hit_position + Vector2(random(-10, 10), -16)
```

飘字漂浮：
```
position.y -= 30 × delta  # 向上漂浮
modulate.a -= 2 × delta   # 淡出
```

命中停顿时间：
```
stop_frames = lookup[event_type]  # 1, 2, 3, 5
stop_duration = stop_frames × (1.0 / 60)  # 假设 60fps
```

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| 同一帧多颗子弹命中同一敌人 | 只触发一次停顿（最长），每个命中独立生成飘字 |
| 命中停顿期间又有新命中 | 新命中排队，停顿结束后执行 |
| 伤害飘字数量过多 | 最多同时 20 个飘字，超出时移除最早的 |
| 玩家和敌人同时死亡 | 两个反馈同时播放，停顿取最大值 |
| 0 伤害命中（无敌期间） | 不生成飘字和反馈 |

## 6. Dependencies

### 依赖
- **射击系统**: 命中事件来源
- **生命值系统**: 伤害计算结果
- **摄像机系统**: 屏幕震动触发

### 被依赖
- **粒子特效**: 可扩展命中特效（VS 阶段）

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|
| 普通命中停顿 | 1 帧 | 0-3 | 命中手感 |
| Boss 命中停顿 | 2 帧 | 1-5 | Boss 命中重量感 |
| 击杀停顿 | 3 帧 | 2-6 | 击杀满足感 |
| 敌人闪烁时间 | 1 帧 | 1-3 | 受击可见性 |
| 伤害飘字速度 | 30 px/s | 20-60 | 飘字可读性 |
| 伤害飘字存活 | 0.5 秒 | 0.3-1.0 | 信息停留时间 |
| 命中闪大小 | 8 px | 4-16 | 命中视觉反馈 |
| 最大同时飘字 | 20 | 10-50 | 性能/可读性 |

### 集成测试

- [ ] 伤害数值与生命值系统一致
