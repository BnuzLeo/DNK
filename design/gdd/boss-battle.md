# Boss 战 (Boss Battle)

*Created: 2026-05-07*
*Status: Draft*
*Priority: MVP — Feature Layer*
*Depends on: 敌人 AI, 生命值系统, 关卡/楼层系统*
*Depended on by: UI/HUD*

---

## 1. Overview

Boss 战系统管理每层末尾的 Boss 战斗。Boss 是高血量、独特攻击模式的敌人，是每层的高潮。击败 Boss 是"再来一局"的核心动力（支柱 3）。

---

## 2. Player Fantasy

玩家感受到的：Boss 是真正的挑战。它有独特的攻击模式，需要学习和适应。击败它时有强烈的成就感。屏幕被 Boss 的 Hot Pink 攻击填满，但我知道怎么躲避。

支柱 1（弹幕爽感）要求：Boss 攻击增加弹幕密度。支柱 2（即时反馈）要求：Boss 受击有明显反馈。支柱 3（上瘾循环）要求：Boss 战是每层的高潮。

---

## 3. Detailed Rules

### 3.1 Boss 属性

| 属性 | 值 |
|------|------|
| 生命值 | 500 |
| 碰撞半径 | 24-32px |
| 移动速度 | 60 px/s |
| 碰撞层 | ENEMY |

### 3.2 Boss 行为模式

Boss 有 3 个阶段，根据生命值百分比切换：

**阶段 1（100%-60% HP）:**
- 行为：缓慢追踪玩家
- 攻击：每 2 秒发射 3 发扇形子弹
- 子弹速度：250 px/s
- 子弹伤害：8

**阶段 2（60%-30% HP）:**
- 行为：追踪玩家 + 偶尔冲刺
- 攻击：每 1.5 秒发射 5 发扇形子弹
- 子弹速度：300 px/s
- 子弹伤害：10
- 新增：每 3 秒发射 8 发环形弹幕

**阶段 3（30%-0% HP）:**
- 行为：频繁冲刺 + 快速移动
- 攻击：每 1 秒发射 5 发扇形子弹
- 子弹速度：350 px/s
- 子弹伤害：12
- 环形弹幕：每 2 秒发射 12 发

### 3.3 Boss 攻击模式

**扇形弹幕:**
- 从 Boss 位置向玩家方向发射多发子弹
- 子弹扇形分布，角度间隔相等
- 阶段 1：3 发，角度间隔 15°
- 阶段 2：5 发，角度间隔 10°
- 阶段 3：5 发，角度间隔 8°

**环形弹幕:**
- 从 Boss 位置向四周均匀发射子弹
- 阶段 2：8 发，角度间隔 45°
- 阶段 3：12 发，角度间隔 30°

**冲刺:**
- Boss 短暂蓄力（0.5 秒），然后高速冲向玩家位置
- 冲刺速度：400 px/s
- 冲刺距离：200px
- 冲刺期间碰撞伤害：20

### 3.4 Boss 告诉

每个攻击前有视觉"告诉"：
- **扇形弹幕**: Boss 闪烁 0.3 秒
- **环形弹幕**: Boss 停止移动 0.5 秒，身体发光
- **冲刺**: Boss 面朝玩家方向，身体缩小 0.3 秒

### 3.5 Boss 死亡

- 生命值归零时触发 `boss_died` 信号
- 播放特殊死亡动画（爆炸 + 屏幕震动）
- 屏幕震动（更强烈，0.5 秒）
- 触发楼层完成

### 3.6 Boss 入场

- 进入 Boss 房间时，屏幕变暗 1 秒
- Boss 从黑暗中出现（Hot Pink 眼睛/轮廓）
- 入场动画 1-2 秒
- 然后战斗开始

## 4. Formulas

扇形弹幕角度：
```
start_angle = aim_angle - (bullet_count - 1) × spread_angle / 2
for i in range(bullet_count):
    angle = start_angle + i × spread_angle
    direction = Vector2(cos(angle), sin(angle))
```

环形弹幕角度：
```
for i in range(bullet_count):
    angle = i × (2π / bullet_count)
    direction = Vector2(cos(angle), sin(angle))
```

阶段切换：
```
if current_hp / max_hp <= 0.6 and current_phase < 2:
    switch to phase 2
if current_hp / max_hp <= 0.3 and current_phase < 3:
    switch to phase 3
```

## 5. Edge Cases

| 场景 | 处理方式 |
|------|----------|
| Boss 被一击秒杀 | 正常处理死亡，不特殊处理 |
| Boss 冲刺时撞墙 | 停止冲刺，返回原位 |
| Boss 在攻击"告诉"期间被大量伤害 | 完成"告诉"后执行攻击 |
| 玩家在 Boss 入场动画期间死亡 | 入场动画继续，然后进入死亡流程 |
| Boss 阶段切换时正在攻击 | 完成当前攻击后切换阶段 |

## 7. Tuning Knobs

| 参数 | 默认值 | 范围 | 影响 |
|------|--------|------|------|

| 阶段 3 阈值 | 30% HP | 20-40% | 最终阶段开始 |

| 冲刺伤害 | 20 | 10-30 | 冲刺惩罚 |
